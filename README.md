# TBSWHP Week 5 Pickem

Static page, no build step. Files: `index.html`, `preview.png` (Discord/social preview).

## Publish on GitHub Pages
1. Create a new public repo named `week5-pickem`.
2. Upload everything in this folder (including the hidden `.nojekyll` if your uploader shows it).
3. Repo Settings > Pages > Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`. Save.
4. After about a minute the site is live at `https://YOUR-USERNAME.github.io/week5-pickem/`.

## Before sharing: set your real URL
In `index.html`, replace `YOUR-USERNAME` (2 places, the `og:image` and `og:url` tags) with your GitHub username. If you name the repo something else, change `week5-pickem` there too. Without this, Discord shows no preview image.
